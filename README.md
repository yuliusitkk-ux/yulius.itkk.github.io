# Yulius — Lecturer & Researcher Portfolio

A responsive personal portfolio built with HTML5, CSS3, Bootstrap 5, and vanilla JavaScript.

## Files
- `index.html` — page content and sections
- `assets/css/style.css` — visual design and responsive layout
- `assets/js/script.js` — navigation, current year, and back-to-top interaction
- `assets/img/` — add your own profile photo and other images here

## Publish with GitHub Pages
1. Upload all files and folders in this package to the **root** of your repository.
2. Open repository **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/(root)`, then click **Save**.
5. Wait for the deployment to complete. GitHub will show the published URL in the Pages settings.

Official guide: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Personalize before sharing
Search in `index.html` for:
- `your.email@example.com` — replace with your professional email
- `Add Google Scholar / SINTA URL` — add your academic profile
- `YEAR – PRESENT`, `YEAR – YEAR` — replace with verified history
- `Project title goes here` — add actual projects and URLs
- `placeholder-link` — replace placeholder links with real links or remove unused ones

Add your photo to `assets/img/` and replace the stylized profile placeholder in the hero section when ready.

## Notes
This is a static website. It does not require PHP, MySQL, or a backend server. Bootstrap and Google Fonts are loaded from CDNs, so an internet connection is needed for those external assets.
